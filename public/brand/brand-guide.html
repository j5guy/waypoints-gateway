Gateway Waypoints

One secure front door for all of your Waypoints apps.

Concept

Every Waypoints icon is a near-black rounded square with dotted trails running out to colored markers and one gold destination marker. Each app puts its own subject in the middle: a daisy for Fond, a clock for Charging, bars for Balanced. The Gateway's subject is an archway. The gold marker sits in the doorway, and four trails fan out from the top of the arch, one to each app's marker color. It is the one icon in the family that points outward at the others.

Usage

  • Use the tile icon wherever the other apps use theirs: tab, home screen, app lists, cards. Use the transparent mark only on a plain background.
  • Keep the four marker colors in the same order (blue, teal, amber, violet). If the Gateway adds a fifth app, add a fifth trail in green rather than recoloring.
  • Gold is reserved for the destination marker. Don't use it for buttons or text.
  • Name: "Gateway Waypoints" in full on first use, "Gateway" after that. The PWA short name is "Gateway".
  • Type: the system UI stack the Gateway already uses. The wordmark is set in bold sans, cream on dark or ink on light.
  • Keep clear space around the icon of at least one marker diameter. Don't stretch it, add shadows, or change the tile color.
